---
title: Installation
description: Add kestrel-chartkit from a release tag and choose its Cargo features.
order: 1
---

```sh
cargo add kestrel-chartkit --git https://github.com/casoon/kestrel-chartkit --tag v0.24.0
```

Or in `Cargo.toml`:

```toml
[dependencies]
kestrel-chartkit = { git = "https://github.com/casoon/kestrel-chartkit.git", tag = "v0.24.0" }
```

<Callout type="note">
  crates.io and docs.rs still carry 0.11.3, thirteen minor versions behind the repository. Pin a
  release tag from the repository instead. The crate is pre-1.0, and a breaking change raises the
  minor version; move to a new tag deliberately.
</Callout>

## Cargo features

| Feature    | Default | Adds                                                                    |
| ---------- | ------- | ----------------------------------------------------------------------- |
| `serde`    | yes     | `Serialize` and `Deserialize` for public data types                     |
| `calendar` | no      | `ExchangeCalendar`: IANA-timezone-aware trading sessions, via `chrono-tz` |

Without default features the crate has no dependencies at all:

```toml
[dependencies]
kestrel-chartkit = { git = "https://github.com/casoon/kestrel-chartkit.git", tag = "v0.24.0", default-features = false }
```

## Requirements

Rust 1.87 or newer (`rust-version` in `Cargo.toml`).

## Try the examples

The repository contains runnable examples:

```sh
git clone https://github.com/casoon/kestrel-chartkit
cd kestrel-chartkit
cargo run --example basic_indicator
cargo run --example synthetic_patterns
cargo run --example site_showcase   # writes the SVG charts shown on this site
```
