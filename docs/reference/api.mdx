## Indicators

<ApiEntry
  kind="fn"
  name="catalog"
  signature={`pub fn catalog() -> Vec<IndicatorCatalogEntry>`}
>
  Every registered indicator with name, description and default parameters.
</ApiEntry>

<ApiEntry
  kind="fn"
  name="output_unit"
  signature={`pub fn output_unit(name: &str) -> IndicatorUnit`}
>
  What an indicator's primary output is quoted in: `Price`, `Ratio`, `Volume` or `Unitless`.
  `Price` means a price level and belongs on the price axis; everything else needs its own scale.
  Unknown names return `Unitless`.
</ApiEntry>

<ApiEntry
  kind="fn"
  name="build_checked"
  signature={`pub fn build_checked(
    name: &str,
    params: &HashMap<String, f64>,
) -> Result<Box<dyn Indicator>, RegistryError>`}
  params={[
    { name: 'name', type: '&str', desc: 'A name from catalog(), e.g. "rsi".' },
    { name: 'params', type: '&HashMap<String, f64>', desc: 'Parameter overrides. Missing keys take the defaults.' },
  ]}
/>

<ApiEntry
  kind="trait"
  name="Indicator"
  signature={`pub trait Indicator: Send + Sync {
    fn on_bar(&mut self, bar: &Bar) -> Option<IndicatorOutput>;
    fn on_checked_bar(&mut self, bar: &Bar) -> Result<Option<IndicatorOutput>, BarValidationError>;
    fn alerts(&self) -> Vec<IndicatorAlert>;
    fn warmup_period(&self) -> usize;
    fn reset(&mut self);
}`}
>
  See [Indicators](../../guides/indicators/) for the output fields.
</ApiEntry>

## Beyond these docs

The crate also exports trade statistics (`stats`, `evaluation`), option and bond valuation
(`option`, `finance`, `valuation`), portfolio risk and stress (`portfolio`, `risk`, `stress`),
bar transforms such as Heikin-Ashi (`transform`) and the optional exchange calendar (`calendar`).
The [README](https://github.com/casoon/kestrel-chartkit#readme) gives an overview.
